# adapt-theme-modern

A clean, accessible, Rise-style theme for the Adapt Framework, forked from `adapt-contrib-vanilla` (GPL-3.0). It uses a system font stack (no external font requests) and the university brand colours (navy and orange) arranged so every text pairing meets WCAG AA contrast.

Designed to be used with `adapt-menu-lessons`. See `../README.md` for details, how to change the palette and what has been verified.
